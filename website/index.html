How to get started

  • 1. Pair Now — tap the button and enter your WhatsApp number
  • 2. Enter the code — link the device in WhatsApp on your phone
  • 3. Download your bootstrap — one file with your Session ID already filled
  • 4. Deploy — upload to your panel and start with node index.js

What you need

  • A WhatsApp account you are allowed to link
  • A host or panel with Node.js 18+ (for example Pterodactyl)
  • Your bootstrap file from this website after pairing

Security

  • Pairing happens only on this official website
  • No Telegram pairing and no terminal phone prompts
  • Your session is not stored in the public GitHub repository
  • Never share your Session ID or bootstrap file

FAQ

Do I need Telegram to pair?

No. Pairing is only through this website.

What is a Session ID?

A public ID like STAIN-XXXXXX that ties your bootstrap to your paired session.

Where do I run the bot?

On your own hosting or panel. After pairing, download the bootstrap and upload it there.

Can I pair again later?

Yes. Start Pair Now again on this site.
