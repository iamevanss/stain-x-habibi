Features

Core tools preserved from the Stain × Habibi runtime.

Kick, promote, warn, antilink, antigstatus, tagall, open/close, and more.

Media toolkit

Play, sticker, toimg, lyrics, TTS, Telegram sticker packs (.tg), status tools.

Owner controls

Sudo system, private/public mode, broadcast, block, prefix, and safe updates.

Requirements

What you need after pairing.

  • WhatsApp account you are authorized to link
  • Hosting / panel that can run Node.js 18+ (e.g. Pterodactyl)
  • Bootstrap file generated after a successful pair
  • FFmpeg on the host for some media features

Security & sessions

How public pairing is designed.

  • Pair only on this website — not via Telegram or terminal
  • Session ID format: STAIN-XXXXXX
  • Protected session storage on the pairing backend — not in the public GitHub repo
  • Bootstrap restores your session on your own panel without editing bot source
  • Never share your bootstrap, session ID, or WhatsApp credentials

How it works

  • 1. Tap Pair Now and enter your WhatsApp number
  • 2. Enter the pairing code in WhatsApp on your phone
  • 3. Receive your Session ID and personal bootstrap
  • 4. Deploy the bootstrap on your panel and start the bot

FAQ

Do I need Telegram to pair?

No. Telegram is not used for WhatsApp pairing. Optional Telegram token is only for the .tg sticker utility after the bot is online.

Where is my session stored?

Protected session material is stored by the pairing service. The public GitHub repo never contains user sessions or secrets.

What is STAIN-XXXXXX?

Your public Session ID. You paste it into the bootstrap file (or it is pre-filled when generated) so your panel can restore the correct session.

Can I re-pair?

Yes. Start a new pair on this site. Old sessions can be revoked by the pairing service.
